# 2. k-mer-based genome-wide association studies (k-mer-GWAS)

This module is intended for genome-wide association analysis using k-mer variation across accessions and corresponding phenotype data. It uses the pan-genomic k-mer map generated by [Module 1](../1.Pangenomic_kmer_map/) as the upstream genomic resource.

## Input resources

- Pan-genomic k-mer map from Module 1.
- Accession-resolved phenotype data.

Accession identifiers must be consistent between the genomic and phenotype datasets. Any additional input requirements, genotype preprocessing, statistical models, filtering criteria and output formats will be documented with the implementation.

## Implementation status

The analysis scripts and detailed execution instructions will be added separately. This directory currently provides an overview of the module only.
